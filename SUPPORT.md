# Getting help

- **First, run `brok doctor`.** It checks your installation, workspace, embedding model, LLM provider, shards and integrations, and prints the fix for anything it finds.
- **Questions** ("how do I...?", "is this expected?"): ask in [Discussions, Q&A](https://github.com/brokspace/brok/discussions/categories/q-a). Paste the output of `brok doctor` (remove anything sensitive).
- **Ideas** you are not sure fit [SCOPE.md](https://github.com/brokspace/brok/blob/main/SCOPE.md) yet: start a thread in [Discussions, Ideas](https://github.com/brokspace/brok/discussions/categories/ideas).
- **Bugs**: open an issue with the bug form in the right repository: the CLI and runtime in [brok](https://github.com/brokspace/brok/issues/new/choose), the default agent in [brok-agent](https://github.com/brokspace/brok-agent/issues/new/choose), the protocol and manifest in [brok-sdk](https://github.com/brokspace/brok-sdk/issues/new/choose).
- **Security issues**: never in public. See the [security policy](SECURITY.md).

Documentation: [brok/docs](https://github.com/brokspace/brok/tree/main/docs) (architecture, configuration, shards, skills, local LLM setup).
