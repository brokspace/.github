# Name and logo policy

The Brokspace code is open source under `MIT OR Apache-2.0`. The Brokspace **name, mark, wordmark and other brand assets** are not part of that grant: they identify the project.

You may use them, unmodified, to:

- refer to Brokspace (articles, talks, tutorials, comparisons);
- link to Brokspace or show that your project works with it ("Works with Brokspace", a shard or skill built for it);
- build Brokspace itself (its repositories, website, documentation, IDE).

Please do not:

- modify the assets, or use them as part of your own product's logo or name;
- suggest that the Brokspace project endorses you when it does not;
- present a fork, a shard or a package as official, or as certified by Brokspace, unless the project says so. Official and certified status is shown by the Brokspace Hub, never by a self-applied badge.

A fork may use, change and redistribute the code under the licenses above; it needs its own name and logo.

When in doubt, open an issue.
